# 配置精简决策

常用路径围绕「选择游戏 → 配置路径 → 开始日常」组织，采用合理默认值与按需展开。游戏目录固定为原神、崩坏：星穹铁道、鸣潮和绝区零，名称与助手类型由程序确定。读取、导入与保存时同步支持列表，保留已有配置并补齐缺少的游戏及其任务。

游戏卡片依次提供「启动助手」「启动游戏」「自动助手」三个按钮。前两个按钮明确选择助手界面与游戏客户端；自动助手沿用独立日常配置和串行队列。顶部保留「开始全部日常」、停止与跳过操作。打开助手界面使用空参数，游戏启动参数与工作目录仅用于游戏客户端。

| 原有选择 | 本轮处理 |
|---|---|
| 游戏路径、助手路径 | 常驻；留空时查找默认安装位置，手动指定优先；未找到时提示选择文件 |
| BetterGI 配置名称、March7th 工作流 | 仅在对应助手的官方自动入口显示；March7th 留空执行默认日常 |
| 助手名称 | 随助手类型确定，移除独立编辑项 |
| March7th 界面入口 | 同目录存在 Launcher 时自动识别；保留手动覆盖 |
| 游戏启动参数、工作目录、助手界面入口 | 收入「更多选项 → 启动方式」；目录默认跟随程序 |
| 日常触发方式、超时、重试 | 使用原有默认值，特殊需要时展开调整；自定义参数仅在自定义命令方式出现 |
| 结果判定、日志路径、三项正则 | 自动识别结果与默认日志；自定义正则仅在日志规则方式出现 |
| 每日执行时间 | 使用 24 小时时间选择器；关闭计划时禁用时间选择 |
| Windows 时区 ID | 收入「时区」，默认北京时间，兼容已有值 |
| 登录启动 | 当前用户开关即时保存，使用最高权限登录计划任务 |
| 配置目录、日志目录、导入导出 | 在「数据」区域直接显示，保留打开日志文件夹 |

设置页采用「常规」「数据」两组平铺布局，组标题沿用原生副标题样式，字段统一左对齐，目录输入框等宽。Hub 配置与助手配置的导入、导出使用相同的列布局，打开日志文件夹位于日志目录下方。

交付程序声明 `requireAdministrator`，由 Windows 在启动时请求管理员权限。助手与游戏通过 CreateProcess 继承 Hub 的权限，任务仍在独立 Job Object 中执行并捕获输出。登录启动使用绑定当前用户的最高权限交互式计划任务；已有启用的注册表启动项迁移成功后清理。计划任务访问失败时显示不可用。

界面测试使用独立的 `asInvoker` 构建与数据目录，仅接受冒烟入口，停用登录启动读写。测试脚本在启动前检查内嵌清单，禁止启动管理员交付程序。

沿用版本 1 配置结构，已有自定义参数、路径、时区、超时及重试值继续保留。精简界面不改变既有任务的执行策略。

助手默认位置按顺序查找当前用户 Programs、系统 Program Files（含 x86）、当前用户 LocalAppData、Hub 所在目录；每个位置下检查 BetterGI、March7thAssistant、ok-ww 对应文件夹中的助手可执行文件。只采用实际存在的文件。读取、导入、保存配置及运行校验均应用相同规则。

游戏客户端留空时依次查找系统 Program Files（含 x86）、当前用户 Programs、Hub 所在目录，以及本地固定磁盘根目录和 Games 目录中的常见安装位置，支持米哈游启动器、HoYoPlay、独立安装的原神、星穹铁道、鸣潮和绝区零。只采用实际存在的客户端，手动路径优先。

BetterGI 安装目录名称依据[官方安装器配置](https://github.com/babalae/better-genshin-impact/blob/0.66.0/Build/kachina.config.json)；March7th 的[官方安装说明](https://m7a.top/)为下载解压，因此其上述目录作为 Hub 的约定查找位置。

## 助手配置导入导出

「设置 → 数据 → 助手配置」提供「导入」「导出」。操作时可多选或全选助手，把所选助手自身的配置文件，连同 Hub 中对应游戏的日常执行方式（触发方式与参数、工作流名称、结果判定与正则、超时、重试、失败后继续）导出为一个 JSON，用于在其它机器复用。

导出先选择助手，再选择文件保存位置，使用 `GameDailyHub.AssistantBundle` 版本 1 JSON；未安装或没有配置文件的所选助手跳过并列出，没有可导出的配置时不生成文件。导入先打开文件，再从文件内的助手中选择恢复项，兼容已有单助手 JSON。仅检查所选助手的目标目录和运行状态，未勾选的助手文件与日常设置保持原样。需先安装所选助手并配置目录；任一所选目标缺失或任一所选文件内容校验失败时，保留原配置。

| 助手 | 导出与导入的文件（相对助手目录） |
|---|---|
| BetterGI | `User/config.json`、`User/OneDragon/*.json` |
| March7thAssistant | `config.yaml` |
| OK-WW | `configs/*.json` |
| 绝区零一条龙 | `config/**/*.yml`、`config/**/*.yaml`，包含全局设置、账号实例、应用组、自定义战斗配置；排除 `.sample.yml`、`.merged.yml`、`config/project.yml`、`config/repository.yml` 和 `run_record` 目录 |

助手目录在二进制模式下为助手可执行文件所在目录，源码模式下为源码目录。文件路径只接受上表模式，导入时拒绝其它路径及越界路径。

导入规则：
- 文件中以盘符或 UNC 开头的绝对路径属于原机器，不会导入：目标机器已有同名设置时保留其值，没有则保持助手默认。JSON 中含此类路径的数组按同样方式处理；March7th YAML 按「键: 值」行处理，保留注释与排版，列表项中的绝对路径会被丢弃。绝区零 YAML 按对象和列表解析，递归保留对应本机路径，重新生成 YAML 排版。
- 其它设置覆盖目标文件；覆盖前把原文件备份为 `原文件名.gdh-时间.bak`。
- 所选助手的文件先在内存中校验与合并，任一失败则不写入任何文件，也不改动 Hub 配置。
- 所选文件暂存并备份后逐个替换；替换失败时恢复已替换文件，备份保留。如果恢复受文件权限或占用影响，会提示使用备份恢复。
- 助手正在运行时拒绝导入，避免其退出时覆盖。
- Hub 侧的安装路径、工作目录、日志路径、助手配置文件路径、源码目录及运行方式属于本机环境，不导出也不覆盖。导入后请核对 Hub 设置，改动自动保存。

助手配置可能含账号、密码、通知地址、密钥等敏感内容，导出文件应妥善保管。Hub 整体配置备份使用「设置 → 数据 → Hub 配置」中的「导入」「导出」。

绝区零配置目录依据官方 [YamlConfig](https://github.com/OneDragon-Anything/ZenlessZoneZero-OneDragon/blob/bdafa6e3/src/one_dragon/base/config/yaml_config.py) 与[用户配置清单](https://github.com/OneDragon-Anything/ZenlessZoneZero-OneDragon/blob/bdafa6e3/.gitignore)接入。
